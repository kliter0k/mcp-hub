# MCP Hub

Локальный MCP-роутер с веб-интерфейсом. Подключает downstream MCP-серверы через `stdio` или Streamable HTTP, объединяет их инструменты с namespace и позволяет скрывать отдельные tools.

В интерфейсе можно останавливать, перезапускать и удалять подключения, а также просматривать популярные каталоги MCP. Каталоги, запрещающие iframe-встраивание, открываются отдельной безопасной вкладкой.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`. MCP endpoint: `http://127.0.0.1:7331/mcp`.

Production-сборка:

```bash
npm run build
npm start
```

## Windows-приложение

```bash
npm run desktop:build
```

NSIS-установщик появится в `release/`. Desktop-версия хранит MCP-конфигурацию в системной папке профиля приложения, запускает локальный endpoint автоматически и не требует отдельного запуска backend.

Состояние сохраняется в `data/state.json`. Переменные из поля `env` передаются дочернему MCP-процессу; не публикуйте этот файл с секретами.
